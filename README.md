[u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).

The entry program writes a single joke (at most 200 characters) to
`/output/entry.txt` — the meeting that refused to die, now in email form:

> Our team finally replaced the weekly status meeting with an email, and
> the email has already scheduled a meeting to discuss the email.

Run with Node 22+: `node main.ts`
